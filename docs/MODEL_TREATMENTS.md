# Blender model treatment reference

All 78 catalog entries are listed below. Native models, animation and sound remain
frozen; these treatments belong to the Blender gallery only. This is a design
reference, not evidence that a model, effect or sound has passed runtime review.

The actual profile code is authoritative: display names come from
[`CatalogInfo`](../scripts/models/CatalogInfo.luau) with
[`CatalogLabels`](../scripts/models/CatalogLabels.luau) overrides; visual labels
come from [`CatalogEffectProfiles.entries`](../scripts/models/CatalogEffectProfiles.luau);
timbres and sound descriptions come from
[`GallerySoundBank.describe`](../scripts/models/GallerySoundBank.luau).
Refresh this table when those definitions change.

The visual column names the temporary accent, not the entire articulated
performance. Timbre is the primary synthesis profile; additional impacts,
harmonics and envelopes can accompany it. Read the
[style guide](MODEL_STYLE_GUIDE.md) and [animation guide](ITEM_ANIMATION_GUIDE.md)
for the surrounding motion and material rules.
